# Naskah demo 3–5 menit

1. (30 detik) Jelaskan masalah: kondisi bising/gelap mengganggu belajar. Tunjukkan dua HP sebagai edge yang berbeda.
2. (45 detik) Tunjukkan hasil pemeriksaan sensor HP A dan HP B. Sebut bahwa nilai hanya hasil pengamatan perangkat kelompok; jika belum diuji, nyatakan hardware belum terverifikasi.
3. (45 detik) Tunjukkan terminal dua edge dan detector. Jelaskan audio tidak dikirim, hanya RMS/dBFS relatif; cahaya dikirim sebagai rata-rata lux.
4. (60–90 detik) Ubah kondisi nyata secara aman: tenang/terang, kemudian uji bunyi singkat dan redup/terang. Tunjukkan hasil status dan rekomendasi dengan timestamp. Tunggu pembaruan, jangan mengarang angka.
5. (30 detik) Hentikan satu edge dan tunjukkan INCOMPLETE_DATA setelah batas stale.
6. (30 detik) Tunjukkan dashboard dari perangkat lain hanya jika akses LAN telah benar-benar berhasil.
7. (30 detik) Tutup dengan keterbatasan kalibrasi, hardware, broker publik, dan kemungkinan perubahan karena variasi HP.

Jika hardware belum siap, jalankan simulator dan sebutkan `SIMULATION` secara jelas di ucapan maupun layar. Jangan presentasikan simulasi sebagai uji sensor nyata.
